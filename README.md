## מבוא

הפרויקט מנהל את **מחזור החיים של המשתמשים והמועדונים** בפלטפורמת שחמט מקוונת – מרגע ההרשמה של שחקן, דרך הפעילות היומיומית שלו, ועד לקשרים החברתיים והשתייכותו למועדונים.

הנתונים הנשמרים ביחידה זו:

- **שחקנים** – פרטים אישיים, מיקום גאוגרפי, שלושה דירוגי ELO נפרדים (Classical, Rapid, Blitz), סטטוס חשבון ותאריך הרשמה.
- **מועדונים** – מועדוני שחמט עם מדינה, עיר, סימון רשמי/לא-רשמי ותאריך הקמה.
- **חברות במועדון** – מי חבר במה, באיזה תפקיד (Owner / Admin / Moderator / Member), מי הזמין אותו, ומתי הצטרף ועזב.
- **מנויים ותוכניות** – תוכניות המנוי של הפלטפורמה, מחזור חיוב, חידוש אוטומטי וטווח תאריכים.
- **יומני התחברות** – מסלול ביקורת מלא לכל ניסיון התחברות: כתובת IP, מיקום, סוג מכשיר, מערכת הפעלה, דפדפן, משך סשן וסימון פעילות חשודה.
- **קשרים חברתיים** – יחסי מעקב/חברות בין שחקנים, לפי סוג קשר וסטטוס.

**הפונקציונליות המרכזית:** ניהול מחזור חיי שחקן · ניהול מועדונים והרשאות לפי תפקיד · מנויים וחיוב · אבטחה וזיהוי פעילות חשודה · גרף חברתי.

## מבנה המאגר

```
README.md              ← המסמך הזה – מבוא כללי וניווט
docker-compose.yml     ← סביבת PostgreSQL 18 + pgAdmin
שלב א/                 ← עיצוב, יצירה, אכלוס וגיבוי
שלב ב/                 ← שאילתות, אילוצים, אינדקסים, טרנזקציות
שלב ג/                 ← אינטגרציה עם אגף נוסף + מבטים
שלב ד/                 ← תכנות PL/pgSQL
```

לכל שלב תיקייה עצמאית, ובתוכה קובץ `README.md` שהוא **דוח הפרויקט של אותו שלב**, לצד קבצי ה-SQL, התרשימים, צילומי המסך והגיבוי המעודכן של אותו שלב.

## הרצת הסביבה

הסביבה עולה כולה דרך Docker. נדרש קובץ `.env` בשורש עם המשתנים
`DB_USER_SECRET`, `DB_PASSWORD_SECRET`, `DB_NAME_SECRET`, `PGADMIN_EMAIL`, `PGADMIN_PASSWORD`.

```bash
docker compose up -d
```

- **PostgreSQL** – `localhost:5432`
- **pgAdmin** – `http://localhost:8080`

בעליית volume ריק, בסיס הנתונים נטען אוטומטית מ-`שלב ד/backup4.sql` – הגיבוי המצטבר העדכני ביותר, הכולל את הסכמה המשולבת של שלב ג יחד עם התוכניות של שלב ד. סקריפטי היצירה והאכלוס של שלב א נשמרים בתיקייה שלהם כתוצר של אותו שלב, ואינם משמשים עוד לאתחול.
