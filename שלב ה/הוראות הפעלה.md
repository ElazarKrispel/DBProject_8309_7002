# הוראות כניסה והפעלה - שלב ה

אפליקציית הניהול של Chess Platform: React בדפדפן, FastAPI בשרת, PostgreSQL 18 ב-Docker. הכול רץ מקומית בכתובת אחת: `http://localhost:8000`.

## 1. דרישות מוקדמות

- **Docker Desktop** פועל.
- **Python 3.11 ומעלה** (`python --version`; ב-Windows לפעמים `py -3`).
- **Node.js 20 ומעלה** עם npm (`node --version`). נדרש רק לבניית ה-frontend.
- קובץ **`.env`** בשורש המאגר עם `DB_USER_SECRET`, `DB_PASSWORD_SECRET`, `DB_NAME_SECRET`, `PGADMIN_EMAIL`, `PGADMIN_PASSWORD` (אותו קובץ שמשמש את `docker-compose.yml`). אופציונלי: `APP_USER` / `APP_PASSWORD` למשתמש הכניסה (ברירת מחדל `admin` / `admin`).

## 2. הרמת בסיס הנתונים

בשורש המאגר:

```powershell
docker compose up -d
```

ב-volume חדש, `שלב ד/backup4.sql` נטען אוטומטית (27 טבלאות, 3 מבטים, הפונקציות, הפרוצדורות והטריגרים). אם קיים volume ישן מהרצות קודמות, הבסיס לא ייטען מחדש; במקרה כזה:

```powershell
docker compose down -v
docker compose up -d
```

בדיקה: `docker ps` מציג `PostgreSQL_DB`.

## 3. הפעלה בפקודה אחת

```powershell
powershell -ExecutionPolicy Bypass -File "שלב ה/start.ps1"
```

הסקריפט בונה את ה-frontend אם צריך, מתקין את תלויות ה-backend, מרים את השרת ופותח את הדפדפן ב-`http://localhost:8000`. להפסקה: `Ctrl+C` בחלון.

## 4. הפעלה ידנית (אם מעדיפים שלב-שלב)

```powershell
cd "שלב ה/frontend"
npm install
npm run build

cd "../backend"
pip install -r requirements.txt
python -m uvicorn app.main:app --port 8000
```

ואז לפתוח `http://localhost:8000`.

מצב פיתוח (טעינה חמה): בתיקיית `frontend` להריץ `npm run dev` ולפתוח `http://localhost:5173`; ה-backend חייב לרוץ במקביל על 8000.

## 5. כניסה

- כתובת: `http://localhost:8000`
- משתמש: `admin`
- סיסמה: `admin`

(ניתן לשנות דרך `APP_USER` / `APP_PASSWORD` ב-`.env`.) תיעוד ה-API: `http://localhost:8000/docs`.

## 6. תסריט הדגמה מומלץ

1. **Dashboard** - ה-KPI, הגרפים, ותג Stage 4 health שמראה שכל אובייקטי שלב ד מותקנים. משם כרטיס ניווט לכל מודול.
2. **Players** (Players & Clubs > Players) - לפתוח שחקן לעריכה ולהעלות את `rating_classical` ב-500: הבסיס דוחה (`Rating change too large`, הטריגר `trg_player_update`). לשנות ל-50: מתקבל. באותו מסך: Update by key (מקלידים `player_id`, Fetch, עורכים, Save), ולשים לב שהסטטוס מוצג כשם ולא כקוד.
3. **Reports > Q2** (Monthly login activity) - להריץ ולראות את הגרף לפי חודש. אחר כך Q5 עם `min_clubs` שונה ומתג A/B עם הסבר היעילות. U1 במצב Preview מציג לפני/אחרי בלי לשנות נתונים.
4. **Programs > fn_club_report** - `country = IL`, `min_members = 25`: ה-NOTICE של הפונקציה והשורות שנשלפו מה-REF CURSOR.
5. **Programs > sp_process_billing_cycle** - `as_of = 2026-08-18`, `limit = 50`, Preview: ערכי ה-INOUT (`renewed` / `expired`), ההודעות, ולפני/אחרי על `player_subscription`. Apply מבצע באמת.

בונוס אם נשאר זמן: הדגמות הטריגרים בתחתית Programs, מצב כהה, ו-`Ctrl+K` לקפיצה לכל טבלה.

## 7. פתרון תקלות

| תופעה | פתרון |
|---|---|
| `address already in use` | פורט 8000 תפוס: `netstat -ano \| findstr :8000` ולסגור את התהליך, או `--port 8001` |
| שגיאת חיבור לבסיס במסך הכניסה | `docker ps`; אם `PostgreSQL_DB` לא רץ: `docker compose up -d` |
| `password authentication failed` | `.env` לא תואם ל-volume הקיים. `docker compose down -v` ואז `up -d` |
| Dashboard: Stage 4 objects missing | volume ישן בלי הרוטינות. `docker compose down -v` ואז `up -d` |
| `frontend not built yet` | `npm run build` בתיקיית `frontend` |
| `npm install` נכשל | לשכפל את המאגר לנתיב באנגלית בלי רווחים ולהריץ משם |
| `python` לא מזוהה | להשתמש ב-`py -3 -m uvicorn app.main:app --port 8000` |
| `start.ps1` חסום | להריץ עם `powershell -ExecutionPolicy Bypass -File ...` כמו למעלה |
